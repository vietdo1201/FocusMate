# Hồ sơ đồng bộ và kiểm chứng FocusMate v2.3.0

Ngày: 2026-09-16. Baseline công khai: `d7c072e3a1ff82395b7d53d0378402c8a9d57918`,
tag `v2.3.0`; Watch code 26, firmware 2.3.0.

## Thành quả đã hoàn thành

- Đã tải refs mới nhất từ GitHub và cập nhật `main` fast-forward đến `v2.3.0`.
- Đã sao lưu đủ 27 file thay đổi local, kiểm tra SHA-256 từng file, tạo Git stash
  và Git bundle để giữ lịch sử cùng nội dung trước đồng bộ.
- Đã bảo toàn thay đổi tài liệu trên `main` sau khi đồng bộ baseline mới.
- Đã đối chiếu release công khai và CI thành công; 16 asset do dự án đính kèm gồm
  APK ký số, firmware, source archive, SBOM, license/notices và checksum.
- Đã đồng bộ đường dẫn sử dụng, changelog, release notes và nguồn tài liệu
  chuẩn. Hành vi 2.3.0 thống nhất với ADR 0008: nghỉ chủ động, check-in tự nguyện,
  advisory yên lặng và Rule Engine độc lập.
- Đã sửa runtime Watch: giữ member JNI/protobuf MediaPipe qua R8, bảo toàn thời
  gian khi migration/recovery, reset focus block sau recovery và chọn foreground
  service type theo quyền trên Android 14+ kèm motion fallback.
- Giữ nguyên tag, artifact phát hành, protocol, model hashes và bộ evidence cũ.

đối chiếu. Source hiện tại kết hợp tài liệu v2.3.0 với bản sửa runtime có regression
test, không thay protocol, model hash hoặc luật `watch_rules_v2`.
