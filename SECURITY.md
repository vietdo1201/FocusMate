# Security policy

Không đăng ảnh khuôn mặt, raw sensor data, signing key, password hoặc token trong issue/public log.

Nếu phát hiện lỗ hổng, hãy dùng GitHub Security Advisory của repository thay vì issue công khai. Chưa có cam kết hỗ trợ cho bản production; trạng thái phần cứng và release readiness nằm trong `docs/STATUS.md`.
